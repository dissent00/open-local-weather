# Reference material

These files are the prior Google Sheets/Apps Script implementation this repo
is rebuilt from — kept here for provenance and as a reference for the exact
verification/scoring math and prompt structure while porting. They are not
part of the running system.

- `KisumuForecastPipeline_v2.gs` — the Apps Script pipeline itself.
- `apps-script-README_v2.md` — its setup/migration notes.
- `CLAUDE_CODE_HANDOFF_BRIEF.md` — the design brief carried over to scope this
  rebuild's architecture (GitHub Actions, git-as-database, GitHub Pages,
  Brevo).
